## 0. 逆向来源与还原度说明

| 资产类型 | 原始形态 | 解包后形态 | 可编辑性 |
|---|---|---|---|
| GDScript 脚本 | `.gd`（明文） | `.gd` 明文源码 | ✅ **完全可读可改**（88 个文件全部还原） |
| 场景 | `.tscn` | `.scn`（二进制）+ `.tscn.remap` | ⚠️ 二进制，需 Godot RE Tools 反编译为 `.tscn` 才能在编辑器编辑 |

**结论**：游戏的全部**逻辑与数值**（脚本）已 100% 还原，可直接阅读、修改、优化。若需在 Godot 编辑器里可视化编辑场景/美术，还需用 Godot RE Tools（gdsdecomp）把 `.scn/.ctex/.oggvorbisstr` 反编译回 `.tscn/.png/.ogg`（详见文末"进一步还原"）。

## 2. 核心架构概览

游戏是一款 **"roguelite 生存射击 + 放置(idle)养成"** 混合类型。整体架构由**一个常驻主场景 + 大量 Autoload 单例 + 三大游戏场景**组成：

```
MainScene (常驻)
 ├─ SubViewport(480×270)  ← 所有游戏内容渲染在低分辨率视口再整数放大
 │   └─ curr_scn: 在以下三者间切换
 │        ├─ MainMenu   (主菜单)
 │        ├─ ShopScene  ("HOME"：升级树/里程碑/矿场/实验室/属性)
 │        └─ BattleScene(战斗：鼠标即角色，自动攻击生存)
 ├─ 后期特效层 (CRT / Glitch / WorldEnvironment 辉光)
 └─ PopupManager / Tooltip / SceneTransition
```

**场景流转**（`MainScene.gd`）：`主菜单 →(new/continue)→ 商店 ⇄ 战斗`。每次切换都会 `Saver.save_game()` 自动存档。

**数据分层**（关键设计）：
- `State`（会存盘）：资源数量、等级、转生、永久加成等。
- `State.stats: Stats`（**不存盘**）：所有战斗属性（伤害/护甲/攻速…），每次读档时由 `UpgradeStore.load_save()` 重新根据已购升级**重算**得出。
- `State.nums: Numbers`（存盘）：累计击杀统计，用于里程碑。
- `State.crypto_mine: CryptoMine`（存盘）：挖矿进度。

## 3. Autoload 单例（`Scripts/Autoloads/`）

按 `project.godot` 中的加载顺序（顺序很重要，后者依赖前者）：

| # | 单例 | 职责 |
|---|---|---|
| 1 | **Layers** | 物理/渲染图层名 → bitmask 映射工具，供碰撞掩码生成 |
| 2 | **Defer** | 把任务推迟到下一帧执行（避免同帧重入） |
| 3 | **Refs** | ★ 全局引用枢纽，集中持有相机/视口/当前场景/各战斗组件的引用；生成 `enemy_mask` 等碰撞掩码 |
| 4 | **Saver** | 存档系统（`user://save.dat`，`var_to_str` 文本序列化，先写 temp 再复制以防写坏） |
| 5 | **UpgradeStore** | ★ **90+ 个升级的全部数据定义**（id/名称/描述/资源类型/各级花费）+ 存读档 |
| 6 | **MilestoneStore** | 25 个里程碑（击杀成就）数据定义 + 存读档 |
| 7 | **Globals** | 全局常量(`SIZE=480×270`)、鼠标坐标/锁、屏震强度；**核心战斗函数** `create_explosion()` / `create_pulse_bolts()` |
| 8 | **Springer** | 弹簧动画管理器（缩放/挤压/旋转"弹一下"反馈） |
| 9 | **Jumper** | 位置"跳跃"补间动画 |
| 10 | **Shaker** | 基于预采样噪声的抖动（相机/UI） |
| 11 | **MyTimer** | 自研计时系统（支持暂停/真实时间/重复），替代 `await`；分秒级与物理帧级 |
| 12 | **ShapeCaster** | 2D 物理形状投射封装（point/circle/box/shape cast），战斗命中检测核心 |
| 13 | **Effects** | 视觉特效工厂（冲击方块/角框/闪电/漂浮文字/通用实例化） |
| 14 | **State** | ★ **核心存档状态**：六种资源、等级/经验、转生、永久血量加成、`stats/nums/crypto_mine` |
| 15 | **SFX** | 音效池（50 个播放器 + 冷却防抖 + 随机音高） |
| 16 | **BGM** | 背景音乐（9 首 Lofi 循环 + 洗牌 + 低通滤波氛围切换） |
| 17 | **OptionData** | 设置持久化（`user://options.dat`：窗口/VSync/屏震/CRT/调色板/音量） |
| 18 | **RTLSizer** | 离屏富文本测量工具（算字符串像素宽做挤压动画） |
| 19 | **MySteam** | Steam 初始化 + 所有权校验（未拥有则退出）+ 成就/统计封装 |

> `Timer/` 子目录：`MyTimer.gd`（管理器）、`TimeInstance.gd`（秒级单元）、`FrameInstance.gd`（帧级单元）。
> `Stores/` 子目录：`UpgradeStore.gd`、`MilestoneStore.gd`。

## 4. 游戏系统（`Scripts/Systems/`）

| 文件 | 职责 |
|---|---|
| **Stats.gd** | ★ 所有战斗属性的容器（约 60 个字段：伤害/暴击/护甲/攻速/血量/掉落/脉冲弹/浮游炮/闪电…），**不存盘**，由升级重算 |
| **Numbers.gd** | 击杀统计（红/蓝/黄敌击杀数、总击杀），存盘，供里程碑判定 |
| **CryptoMine.gd** | ★ 挖矿系统：`1 Bit → 0.00001 Netcoin`，37 级速度表（5→128万 bits/s），存款/升级/换算 |

## 5. 升级系统（`Scripts/Upgrades/` + `Shop/`）

| 文件 | 职责 |
|---|---|
| **Upgrade.gd** | 单个升级的数据类（id/图标/名/描述/资源类型/`costs[]`/当前等级/`can_buy()`） |

| **Shop/UpgradeTree.gd** | 升级树容器：画连线、按依赖显隐节点、点击购买、边界约束的平移 |
| **Shop/UpgradeNode.gd** | 单个升级节点（图标 + 描边着色 + 点击/悬停信号） |
| **Shop/UpgradesPage.gd** | 升级树页面（方向键移动 + 右键拖拽 + 滚轮缩放） |
